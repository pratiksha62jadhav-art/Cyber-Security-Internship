# Task 5: Wireshark Network Traffic Analysis

## Objective
Capture and analyze network traffic using Wireshark.

## Tool Used
Wireshark 4.6.9

## Protocols Identified
- **TCP:** Reliable data transmission.
- **TLS:** Encrypted network communication.
- **UDP:** Connectionless data transmission.
- **DNS:** Resolves domain names to IP addresses.

## Steps Performed
1. Captured network traffic on the Wi-Fi interface.
2. Visited a website to generate traffic.
3. Saved the capture in PCAPNG format.
4. Applied TCP, TLS, and UDP display filters.
5. Observed DNS queries and responses.

## Evidence
Screenshots of TCP, TLS, and UDP/DNS filters will be added to this folder.

## Conclusion
Wireshark was used to capture and inspect network packets and identify common network protocols.
