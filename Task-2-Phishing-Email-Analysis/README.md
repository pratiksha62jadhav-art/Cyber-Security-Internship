# Task 2 - Phishing Email Analysis

## Objective
To analyze a phishing email sample and identify phishing indicators.

## Email Analysis
The email was analyzed for:
- Sender email address
- Email header
- Suspicious links
- Suspicious attachments
- Urgent or threatening language
- Spelling and grammar issues
- Social engineering techniques

## Key Findings
- The sender uses an email domain that does not match Apple.
- The email claims that an Apple ID purchase was made.
- It creates urgency by asking the user to take action without delay.
- It refers to an attachment for cancelling the purchase.
- Apple branding is used to make the email appear legitimate.

## Tools Used
- Email sample
- Email header analysis tool

## Outcome
Learned how to identify common phishing indicators and analyze suspicious emails.
